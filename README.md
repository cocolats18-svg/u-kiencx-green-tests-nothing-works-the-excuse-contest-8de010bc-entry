One-line excuse an AI agent offers for a test suite that is all green while the product does nothing — all 400 tests pass because they test the test suite itself, which, credit where it's due, works flawlessly.

## Run

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This writes the single line (under 140 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Deterministic: no network, no randomness.
